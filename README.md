# 六爻装卦（京房纳甲） · liuyao-najia

> 给定六爻阴阳与起卦时间，装出完整卦表。

按京房纳甲法（《增删卜易》体系）装卦：输出八宫归属与卦名、世爻应爻、纳甲干支与五行、六亲、六神、伏神、变卦（含完整卦形）、旬空、六冲／六合。

**只做盘面计算，不判吉凶。** 纯 Python 标准库实现，默认全程不联网。

---

## 它解决什么问题

手工装卦的出错点集中在四处，且都是「错了不易察觉」的类型：

- **世应位置**记混，整张表跟着错；
- **六亲按变卦宫取**（应为按本卦宫取），与主流排盘不一致；
- **伏神要翻到表外逐行比对**，抄写时极易漏；
- **年柱月柱以日期为界**（应以立春与十二节的**时刻**为界），交界日前后必错。

本工具把这些规则写成程序，并逐项实测过（见下文「精度与校验依据」）。

## 能做什么

| 功能 | 用法 | 说明 |
|---|---|---|
| 装卦 | `--gua "上离下巽" --dong 6` | 输出八宫、卦名、世应、纳甲、六亲、六神、伏神（标进对应爻行）、变卦（含完整卦形）、旬空、六冲／六合 |
| 多样写法 | `--gua "火风鼎"` / `--gua "上卦为离，下卦为巽"` | 经卦、卦名、简称、口语、倒装、六位阴阳四类写法皆可 |
| 解析卦表 | `--parse-text 文件.txt` | 把论坛标准装卦表文本转成结构化数据 |
| 校验卦表 | 随解析自动执行 | 三层校验：宫位自洽、纳甲逐爻、六亲归属 |
| 自检 | `--self-test` | 内置 96 项断言 |
| 要点梳理（可选） | `--llm` | 接入**你自己**的大模型密钥，在卦表之后追加一段卦象要点梳理 |

## 快速开始

```bash
# 装卦（推荐：直接给四柱，最精确）
python3 scripts/liuyao_zhuanggua.py --gua "上离下巽" --dong 6 \
    --ganzhi "丙午 丁酉 戊子 戊午"

# 直接报卦名（含唯一简称），与上面等价
python3 scripts/liuyao_zhuanggua.py --gua "火风鼎" --dong 6 \
    --ganzhi "丙午 丁酉 戊子 戊午"

# 口语写法亦可，标点与空格随意
python3 scripts/liuyao_zhuanggua.py --gua "上卦为离，下卦为巽" --dong 6 \
    --date "2026-09-14 12:45"

# 用公历时间（年柱月柱按内置精确节气表判定，可精确到分钟）
python3 scripts/liuyao_zhuanggua.py --gua "上震下艮" --dong 1,2,5 --date "2026-09-14 12:45"

# 静卦 / JSON 输出 / 写入文件（Windows 控制台中文乱码时用 --out）
python3 scripts/liuyao_zhuanggua.py --gua "上兑下坎" \
    --ganzhi "丙午 丁酉 戊子 戊午" --json --out result.json

# 用六位阴阳直接指定（自下而上，1=阳 0=阴）
python3 scripts/liuyao_zhuanggua.py --gua-bin 100101 --dong 1 --date "2026-09-14 12:45"

# 解析并校验论坛装卦表文本
python3 scripts/liuyao_zhuanggua.py --parse-text dump.txt

# 自检
python3 scripts/liuyao_zhuanggua.py --self-test
```

## 输入约定

- **六爻位序**：字符串自下而上，第 1 位是初爻；`1` 为阳爻、`0` 为阴爻。
  例：乾为天 `111111`；火雷噬嗑 `100101`（下震 `100` + 上离 `101`）。
- **本卦写法**（下列等价，标点空格随意）：

| 写法 | 示例 | 说明 |
|---|---|---|
| 经卦写法 | `上离下巽` | 先上卦、后下卦；卦名（乾兑离震巽坎艮坤）与别名（天泽火雷风水山地）均可 |
| 口语写法 | `上卦为离，下卦为巽` | 「卦」「是」「为」等虚词可省可留 |
| 倒装写法 | `离上巽下` | 与第一种同义 |
| 卦名写法 | `火风鼎`、`火风鼎卦` | 六十四卦标准名 |
| 卦名简称 | `鼎`、`噬嗑`、`小过` | 仅限在六十四卦内唯一的简称；重名时不收录，须写全名 |
| 六位阴阳 | `011101` | 与 `--gua-bin` 等价 |

- **动爻**：`--dong "5"` 或 `--dong "1,2,5"`；留空即静卦；越界（如 7）直接报错。
- **起卦时间**（二选一）：`--ganzhi "丙午 丁酉 辛卯 甲午"`（推荐，四柱直接给定）或 `--date "2026-09-14 12:45"`（日柱时柱由引擎推算）。

**认不出的写法一律明确报错并列出可用写法，不猜测、不将就。**

## 输出字段

- `ben_gua`：卦名、所属宫（八宫）、宫内位置（本宫／一世……游魂／归魂）、世爻与应爻位置、上下经卦
- `lines`（初爻 → 六爻）：阴阳、纳甲干支、地支五行、六亲、六神、是否世／应、是否动爻、是否旬空；文本输出的爻表另设「伏神」列，把该爻伏神**直接标在本行**
- `fushen`：本卦不现的六亲，取本宫首卦同爻位干支为伏神，标注伏于何爻之下
- `chonghe`（本卦与变卦各一）：按纳甲地支判定卦的冲合——初—四、二—五、三—六三对爻位地支**全部相冲**为「六冲卦」，**全部相合**为「六合卦」
- `bian_gua`：变卦**完整卦形**——卦名、宫位、宫内位置、五行、世应，以及六爻逐爻的阴阳、纳甲干支、五行、六亲（按本卦宫定）、世应标记、旬空、是否动爻
- `time`：年、月、日、时四柱与旬空

## 关键口径（易错点）

1. **变爻六亲按本卦宫定**，不按变卦宫——与主流排盘一致。
2. **世应相隔三爻**：世一应四、世二应五、世三应六、世四应初、世五应二、世六应三。
3. **六神按日干起**：甲乙日起青龙、丙丁日起朱雀、戊日起勾陈、己日起螣蛇、庚辛日起白虎、壬癸日起玄武，自初爻依次向上循环。
4. **旬空按日柱所在旬取**（如辛卯日属甲申旬，空午未）。
5. **归魂卦**＝游魂卦的内卦回本宫（等价于只反第五爻）；本宫（八纯卦）皆为六冲卦。
6. **年柱以立春时刻为界、月柱以十二节时刻为界**，判据是**时刻**而非日期。例如 2026 年立春在 2 月 4 日 04:01，则当日 03:00 起卦仍属上一年乙巳年、丑月。
7. **子时（23:00—23:59）按通行口径归次日**：日柱推进一日，时柱以次日日干起子时。
8. **六冲／六合按纳甲地支现算，不按卦名死记**：程序按规则现算，非查表硬编码，判据可逐卦复核。

更完整的规则表（八宫卦序、纳甲表、六亲取法、伏神取法）见 [`references/zhuanggua-rules.md`](references/zhuanggua-rules.md)。

## 精度与校验依据

本工具的正确性经过逐项实测，不是「大概对」：

| 项目 | 实测方式 | 结果 |
|---|---|---|
| 日柱 | 与寿星天文历（sxtwl 2.0.7）逐日比对 1900-01-01 至 2100-12-31 | 73,414 天**零差异**；另经 lunar_python 交叉核对一致 |
| 旬空 | 同期 73,414 天逐日比对 | 零差异 |
| 节气 | 内置 1900—2100 共 2,412 个「节」的精确时刻（分钟精度） | 逐条与 lunar_python 比对，偏差 ≤ 1 分钟 |
| 年柱／月柱 | 14,683 天抽样 ＋ 2,412 个节气时刻前后 ±2 分钟共 4,824 个边界点 | 全部与独立参考实现一致 |
| 时柱 | 2026 全年每日 24 个整点共 8,760 次比对 | 零差异（含子时归次日） |
| 装卦规则 | 另写独立实现（反推上下经卦、以「首支＋阳顺阴逆」生成纳甲、以五行关系矩阵生成六亲），对 64 卦 × 六爻全字段比对 260 项 | 零问题；并与真实卦表逐爻一致 |
| 输入写法 | 六十四卦逐个以「标准卦名」与「上X下Y」两路直输，另测同一卦十种写法 | 128 例全部还原正确；无法识别的写法一律报错 |
| 六冲／六合 | 对 64 卦全量按规则判定 | 六冲十卦（八纯卦加天雷无妄、雷天大壮）、六合八卦（地天泰、天地否、雷地豫、地雷复、火山旅、山火贲、水泽节、泽水困）逐一吻合 |

超出 1900—2100 年范围时，年柱／月柱退回近似公式推算，程序会在输出中**明确标注「为近似值，请核对」**。

## 可选：接入你自己的大模型

装卦本身不需要模型。若希望卦表之后另附一段**卦象要点梳理**（用神取法、用神与月建日辰的五行关系、动变生克、世应关系、伏神与旬空），可启用 `--llm` 并自备密钥。

```bash
# 先体检：看当前配置状态，不发起任何调用，密钥以掩码显示
python3 scripts/liuyao_zhuanggua.py --llm-doctor

# 预演：只打印会发出去的内容，不外发，用于先确认送出去的是什么
python3 scripts/liuyao_zhuanggua.py --gua "上离下巽" --dong 6 --ganzhi "丙午 丁酉 戊子 戊午" --llm --llm-dry-run

# 正式调用
python3 scripts/liuyao_zhuanggua.py --gua "上离下巽" --dong 6 --ganzhi "丙午 丁酉 戊子 戊午" --llm --llm-key <你的密钥>

# 接本机模型：数据不出本机，无需密钥
python3 scripts/liuyao_zhuanggua.py --gua "火风鼎" --dong 6 --ganzhi "..." --llm --llm-provider local
```

**默认路径的网络隔离是硬性的**：不带 `--llm` 时全程**不加载** `urllib.request`、`http.client`、`ssl`——网络模块只在 `--llm` 分支内部延迟导入。此项已写成自检断言，随每次 `--self-test` 复算。

**密钥展示一律用掩码**（`sk-ab……XYZ（共 44 位）`），完整密钥不出现在任何输出、日志或结果文件中。若不慎贴出，可放心截图。

## 边界与免责

- **只做盘面计算**。工具负责卦象结构的整理与核对：宫位、世应、纳甲、六亲、六神、伏神、变卦、旬空。
- **不做吉凶判断**。不给预测结论、不给行动建议、不判吉凶。启用 `--llm` 后的解读段梳理财象要点，均属盘面内部关系的陈述，**同样不含吉凶结论、不含建议、不预测应期**。
- **可选解读层默认关闭**，开启后由使用者自备密钥、自负费用；该段内容的准确性由所指定的模型负责。
- **不替使用者猜数**。卦名不在标准名内、经卦认不出、动爻越界，一律明确报错。

**六爻属传统术数，本工具是排盘与规则核对的辅助手段，不具科学预测效力。** 请勿据此替代医疗、法律、投资等专业判断。
